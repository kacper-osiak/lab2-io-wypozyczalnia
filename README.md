# Inżynieria Oprogramowania – Laboratorium nr 2

**Temat:** Wypożyczalnia sprzętu turystycznego – modelowanie procesów biznesowych w notacji BPMN.

Zespół przygotował koncepcję systemu informatycznego dla wypożyczalni sprzętu turystycznego (namioty, plecaki, śpiwory). Każdy członek zespołu zamodelował jeden proces biznesowy na diagramie BPMN. W diagramach użyto bramek XOR, AND i zdarzeniowych, zdarzeń komunikatu i czasowych oraz przepływów komunikatów.
